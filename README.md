# second-brain

Tooling for a personal knowledge system built on Obsidian and Claude Code.

This repo holds the skills, scripts, and design record. **The notes themselves
live in a separate private repository** — they have a different life, make
thousands of trivial commits, and are never shared.

| File | What it is |
| --- | --- |
| `DESIGN.md` | What was decided and why |
| `vault-template/` | Scaffolding for a new vault repo |
| `.claude/skills/` | Installed skills |

Start with `DESIGN.md`.
