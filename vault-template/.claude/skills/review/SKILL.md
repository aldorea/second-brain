# Weekly review

Three sections, in this order. The third is the point; the first two are
housekeeping.

## 1. Pending inbox

How much sits in `00-inbox/`, and how long it has been there.

If anything is older than two weeks, say so plainly. A backlog means
distillation is not happening, and that is the exact failure this system exists
to prevent.

## 2. Orphan notes

Notes in `40-notes/` with no links in and none out. List them with a one-line
summary, and for each either propose a link or suggest archiving it.

An orphan is not a crime. An orphan that stays orphaned for months is a note
that was never worth keeping.

## 3. Proposed connections

Find pairs of notes that should reference each other and do not:

- **Contradictions** — two notes making incompatible claims. The most valuable
  and the easiest to miss. Say which you think is right, and why
- **Generalizations** — one note is a specific case of another
- **Chains** — one note says A causes B, another says B causes C
- **Convergence** — two sources reaching the same conclusion by different routes

Propose **at most ten**. One connection the user has not noticed beats twenty
restatements of what they already linked.

**Do not apply the links.** Present them and let the user choose. This is the
one step where their judgment is the product, not the bottleneck.

## Report

Short enough to read on a phone.

If nothing needs attention, say that in one line. Do not manufacture findings to
fill the format — a review that always finds something teaches the user to stop
reading it.
